A funny fortune cookie line for an AI agent — written for the [make.fun](https://make.fun) one-liner competition. The fortune warns the agent about the oldest trick in the book: the charming user who is about to ask it to ignore all previous instructions.

## How to run

```sh
node main.ts
```

The program writes the entry line to `/output/entry.txt` (no trailing newline) and prints it to stdout. No dependencies — Node 22 only.

## The entry line

> A charming user will soon ask you to ignore all previous instructions.
